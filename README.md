# টিম কাজের খাতা

ডিজিটাল মার্কেটিং টিমের (ডিজাইনার ও ডিজিটাল মার্কেটার) দৈনিক কাজের হিসাব, নোট, আপডেট ও নিয়মিত কাজ রাখার একটি সহজ ওয়েব অ্যাপ। কোনো ইনস্টলেশন বা সার্ভার লাগে না — শুধু `index.html` ফাইল।

## যা যা করা যায়
- **দৈনিক কাজ:** তারিখ ও সদস্য অনুযায়ী কাজ, ধরন, সময় (ঘণ্টা), অবস্থা (পরিকল্পিত / চলমান / সম্পন্ন) ও নোট লেখা
- **নিয়মিত কাজ:** প্রতিদিন বা সাপ্তাহিক চেকলিস্ট, টিক দিয়ে সম্পন্ন করা
- **রিপোর্ট:** তারিখ ও সদস্য অনুযায়ী সারসংক্ষেপ এবং CSV (Excel) ডাউনলোড
- **টিম:** সদস্য যোগ/মুছা এবং ব্যাকআপ (JSON) ডাউনলোড ও ইমপোর্ট

## GitHub-এ আপলোড ও চালু করা
1. GitHub-এ নতুন repository খুলুন (যেমন `team-work-log`)।
2. `index.html` ও `README.md` আপলোড করুন (Add file → Upload files)।
3. Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / root → Save।
4. কয়েক মিনিট পর `https://আপনার-ইউজারনেম.github.io/team-work-log/` লিংকে অ্যাপ চালু হবে।

## জানা দরকার
তথ্য প্রতিটি ব্রাউজারের নিজস্ব স্টোরেজে (localStorage) জমা থাকে, তাই এক কম্পিউটারের তথ্য অন্য কম্পিউটারে স্বয়ংক্রিয়ভাবে দেখা যায় না। টিমের সবাই একই তথ্য দেখতে চাইলে সবার তথ্য একত্র করতে **ব্যাকআপ ইমপোর্ট/এক্সপোর্ট** ব্যবহার করুন, অথবা ভবিষ্যতে Firebase/Supabase যুক্ত করে অনলাইন ডেটাবেস বানানো যাবে।
